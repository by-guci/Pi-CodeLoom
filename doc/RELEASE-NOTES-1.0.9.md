## Pi-CodeLoom v1.0.9

本次更新新增中文插件商店与一键更新，并完善模型思考等级、主题通知和窗口关闭体验。

### ✨ 新增

- **中文插件商店**：在“设置 → 插件商店”浏览 pi.dev 官方目录，支持搜索、分类、排序和分页；常用插件提供中文简介，可查看作者原文，无翻译调用费用
- **插件安装与管理**：支持本机用户级 npm 插件的安装、卸载、检查更新和更新／修复，同时显示当前安装版本与 npm 最新版本
- **一键更新已安装插件**：逐个更新符合版本约束的插件，显示进度及每项结果；保留固定版本，单项失败不影响其余更新，有任务运行时阻止开始更新
- **窗口关闭选项**：在“设置 → 通用”选择关闭主窗口时退出应用或最小化到系统托盘；托盘模式下任务继续运行，托盘菜单“退出”仍会彻底退出
- **旧模型自动补全**：自动为已配置模型补齐有资料可查的思考档位映射，保留自定义映射和明确禁用项；断网时跳过并重试，Worker 运行期间延后写入

### 🐛 修复

- 修复自建／中转模型因缺少档位映射而隐藏 XHIGH、MAX 的问题，新增模型导入时同步完整映射
- 支持带日期后缀的模型回退匹配基础模型，如 `deepseek-v4-pro-0813` → `deepseek-v4-pro`；优先使用精确记录，实际请求保留原模型 ID
- 修复新对话切换模型后，输入区继续显示上一个模型思考等级的问题
- 修复更新说明直接显示 `<h2>`、`<li>` 等 HTML 标签的问题，正确排版 HTML、Markdown 和纯文本说明，并过滤可执行内容

### 🎨 界面与体验

- **主题通知卡片**：自动模式优先使用自定义通知，背景、文字、边框及按钮适配 16 套配色与浅色／深色模式；保存主题后卡片同步更新
- 移除自定义通知卡片中的“勿扰 30 分钟”按钮，保留关闭和返回会话操作
- 将临时对话的原生删除确认框改为应用内主题弹窗，删除／取消按钮跟随配色；默认聚焦取消，支持 Esc 关闭

### 使用说明

- 插件商店当前管理本机用户级 npm 包；WSL 支持浏览，WSL、项目级、Git 及本地路径包仍通过 Pi CLI 管理。安装或更新插件后需彻底退出并重启应用
- 模型能力资料用于生成可选档位；通过中转站调用时，实际参数支持仍以该服务为准
